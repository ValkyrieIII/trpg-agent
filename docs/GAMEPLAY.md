# TRPG Agent 游玩指南

## 概述

TRPG Agent 是一个 AI 驱动的单人跑团应用。你扮演冒险者**艾琳**——一位北境荒原游侠，AI 担任地下城主（GM）负责叙事、检定和 NPC 扮演。

## 你的角色：艾琳

**背景：** 北方荒原的游侠，曾在荒野独自生存十年。沉默寡言但行动敏锐，习惯在开口前先观察。

**属性：** 力量14 | 敏捷18 | 智力12 | 意志15

**技能：** 追踪75 | 弓箭80 | 野外生存90

## 游戏机制

### 1. 行动与对话

输入你想做的事。用括号声明行动，也可以直接对 NPC 说话。

```
> (我推开酒馆的门，扫视屋内)
> 老马，最近有什么新鲜事？
> (我拔出短刀，潜行靠近矿洞入口)
```

每次输入会触发：
- **GM 叙事** — GM 描述场景和结果
- **记忆检索** — 回忆历史互动
- **知识检索** — 世界观相关信息
- **状态变化** — 情绪/信任/体力自动变化

### 2. 骰子检定

```
> /dice d20          → 投掷 20 面骰
> /dice 3d6          → 投掷 3 个 6 面骰
> /dice 2d6+3        → 投掷 2d6+3
> 掷骰 2d6+3          → 同样效果
```

### 3. 角色信息

```
> 查看状态
> 查看属性
> 角色卡
```

### 4. 行动检定

用括号声明行动时，GM 会自动判断是否需要检定：

```
> (我追踪地上的脚印)
→ 【追踪检定】d100 ≤ 75 → 成功，你发现了兽人的踪迹

> (我攀爬城墙)
→ 【难度检定 DC12】d20+2 = 15 → 成功，你翻过了城墙
```

纯扮演动作（微笑、点头）不会触发检定。

### 5. NPC 互动

直接对 NPC 说话，GM 会以该 NPC 的身份回应：

```
> 老马，来杯你最好的麦酒！
[GM] 老马从柜台后面抬起头，咧嘴一笑。
[老马] 北境最好的麦酒！喝了我的酒，冰龙都不怕，是吧。
```

GM 会在叙事中动态引入新 NPC，所有 NPC 会被自动记录。

## 角色状态系统

| 维度 | 范围 | 说明 |
|------|------|------|
| 情绪 | calm → wary → hostile | 遭遇背叛/威胁上升，获得帮助下降 |
| 信任 | 0.0 ~ 1.0 | NPC 对玩家的信任程度 |
| 体力 | fresh → tired → exhausted | 战斗/长途消耗，休息恢复 |

---

## 命令速查

| 命令 | 效果 |
|------|------|
| `/dice 表达式` | 投掷骰子 |
| `查看状态` | 显示角色属性和当前状态 |
| `exit` / `退出` | 结束游戏 |
| 其他任意文本 | 行动或对话 |

## 配置自定义

### 更换角色

编辑 `config.yaml`，修改 `player` 下的内容。

### 添加 NPC

在 `data/npcs/` 下创建 `.yaml` 文件，格式参考 `老马.yaml`。

### 添加世界观知识

在 `data/knowledge/` 下创建 `.md` 文件。
