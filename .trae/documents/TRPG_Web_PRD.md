## 1. 产品概述

一个基于"诡秘之主"世界观的 TRPG 跑团 Web 前端界面，替代现有的 CLI 终端交互。玩家通过浏览器与 AI GM 进行沉浸式冒险，支持流式输出、角色状态面板、NPC 交互等核心功能。

- 目标用户：单人 TRPG 玩家、诡秘之主粉丝
- 核心价值：将粗糙的终端输出转化为沉浸式、美观的跑团体验

## 2. 核心功能

### 2.1 功能模块

1. **主游戏界面**: 对话流显示区（流式输出）、角色状态侧栏、快捷操作栏
2. **开场/续接界面**: 新游戏或加载存档的选择界面
3. **设置面板**: 通过按钮触发的弹窗，管理 NPC、世界观、游戏配置

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 主游戏界面 | 对话流 | GM叙述流式显示，玩家输入区，消息气泡区分GM和玩家 |
| 主游戏界面 | 角色状态面板 | HP、疯狂值、情绪、信任、体力实时展示 |
| 主游戏界面 | 快捷操作 | 投骰子按钮、建议列表（可点击）、世界构建命令 |
| 主游戏界面 | 设置按钮栏 | 顶部工具栏，包含 NPC管理、世界观设置、游戏设置 三个按钮 |
| 开场界面 | 开始/续接 | 新游戏按钮、加载存档按钮 |

### 2.3 弹窗设置模块

| 弹窗名称 | 功能描述 | 触发方式 |
|---------|---------|---------|
| **NPC 管理弹窗** | 查看当前场景 NPC 列表、创建新 NPC（自然语言描述）、编辑/删除 NPC、查看 NPC 状态和对话历史 | 顶部"NPC"按钮 |
| **世界观设置弹窗** | 查看已加载的世界观知识、添加新知识（自然语言描述）、编辑/删除知识条目、按分类筛选 | 顶部"世界观"按钮 |
| **游戏设置弹窗** | 查看/修改角色卡、保存/加载存档、调整游戏参数（调试模式等）、查看世界模拟开关 | 顶部"设置"按钮 |

## 3. 核心流程

```
玩家打开页面 → 选择新游戏/续接 → 进入主游戏界面
    ↓
GM 流式输出场景叙述 → 显示建议列表 → 玩家点击/输入行动
    ↓
后端处理（骰子/检定/NPC对话）→ GM 流式输出结果 → 循环
    ↓
玩家点击设置按钮 → 弹出对应弹窗 → 管理 NPC/世界观/游戏配置 → 关闭弹窗继续游戏
```

## 4. UI 设计风格

- **主题**: 维多利亚哥特风格，暗色调（深煤黑 + 古铜金 + 暗红）
- **字体**: 标题使用 serif 字体（体现维多利亚时代感），正文使用清晰易读的无衬线字体
- **布局**: 左侧主对话区（70%）+ 右侧状态面板（30%），桌面优先
- **动效**: 打字机流式文字效果、消息淡入、建议列表悬停高亮、弹窗滑入动画
- **视觉元素**: 分隔线使用装饰性花纹、引用块使用羊皮纸纹理
- **弹窗设计**: 半透明遮罩、羊皮纸背景、装饰性边框、关闭按钮（X）

## 5. 响应式

桌面优先（最小宽度 1024px），平板和移动端自适应布局
