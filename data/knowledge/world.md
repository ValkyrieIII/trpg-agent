# 诡秘之主跑团世界背景设定
**版本**：v1.0（基于原著第五纪1350年前后）  
**适用系统**：COC 7th/自定义诡秘系统  
**推荐人数**：3-5人  
**难度等级**：中等（建议有一定跑团经验）

## 前言
本设定基于爱潜水的乌贼所著《诡秘之主》原著，聚焦于第五纪"蒸汽与机械的时代"，以鲁恩王国为核心舞台，为跑团游戏提供完整的世界观基础。

跑团主持人（KP）可根据团队情况调整设定细节，本背景优先保留原著核心设定，同时补充了适合跑团探索的边缘区域和冒险可能性。玩家将扮演刚刚踏上非凡之路的序列9或序列8非凡者，在这个"愚者"克莱恩·莫雷蒂尚未成为神话的时代，探索蒸汽与神秘交织的黑暗世界。

## 一、时代背景：蒸汽与机械的黎明
### 1.1 历史脉络
- **第一纪**：混沌纪元，造物主创造世界，分裂出最初的古神
- **第二纪**：古神纪元，八大古神统治世界，人类处于被奴役状态
- **第三纪**：灾变纪元，古神陨落，人类崛起，"原初魔女"带来灾变
- **第四纪**：众神纪元，天使之王与真神争夺权柄，"四皇之战"终结时代
- **第五纪**：蒸汽纪元（当前），工业革命兴起，科学与神秘并存

### 1.2 当前时代特征
- **时间点**：第五纪1350年前后（原著故事开始前约1-2年）
- **技术水平**：第一次工业革命鼎盛期，蒸汽机广泛应用，铁路贯通大陆，电报开始普及
- **社会结构**：封建贵族与新兴资产阶级并存，贫富差距巨大，城市贫民窟问题严重
- **宗教状况**：七大正统教会占据主导地位，隐秘组织在地下活动
- **时代氛围**：表面繁荣的工业文明下，隐藏着疯狂与神秘的暗流。非凡力量如同毒药，既带来力量，也带来疯狂与死亡。

## 二、地理设定
### 2.1 主要大陆
- **北大陆**：人类文明的中心，包括鲁恩王国、因蒂斯共和国、费内波特王国、弗萨克帝国等国家
- **南大陆**：被称为"神弃之地"，原始落后，存在大量古老遗迹和危险生物
- **东大陆**：传说中的"太阳之地"，被迷雾笼罩，几乎无人知晓其真实面貌
- **西大陆**：完全被"狂暴海"隔绝，无人能够到达

### 2.2 核心舞台：鲁恩王国
**首都**：贝克兰德（"万都之都"，人口超过500万）
- **上城**：贵族与大资产阶级的居住地，环境优美，守卫森严
- **中城**：中产阶级、商人、专业人士的聚居区
- **下城**：工人阶级的居住地，环境恶劣，犯罪率高
- **东区**：最贫困的区域，贫民窟遍布，是各种地下势力的温床
- **码头区**：货物集散地，鱼龙混杂，走私活动猖獗

**主要城市**：
- 廷根：鲁恩王国西北部城市，黑夜女神教会的重要据点
- 恩马特港：重要的港口城市，贸易发达
- 康斯顿：工业城市，以钢铁和机械制造业闻名
- 普利兹港：皇家海军基地

## 三、非凡体系：22条神之途径
### 3.1 基本概念
- **非凡特性**：非凡力量的本质，包含对应序列的全部能力和知识
- **魔药**：由非凡特性搭配辅助材料制成，服用后可获得对应序列的力量
- **扮演法**：正确消化魔药的方法，核心是"扮演什么，就像什么"
- **失控**：未能正确消化魔药或受到精神污染导致的疯狂状态，最终会变成怪物
- **锚**：非凡者用来稳定自身精神状态的事物，通常是信仰、执念或重要的人

### 3.2 序列体系
非凡者从低到高分为9个序列，序列1为天使之王，序列0为真神。

| -------- | -------------------------- | -------------------------------------- | -------- |
| 序列9    | 学徒                       | 获得基础非凡能力，身体素质小幅提升     | 低       |
| 序列8    | 格斗家/观众/药师等         | 能力明显增强，开始展现途径特色         | 低-中    |

### 3.3 核心规则体系

#### 3.3.1 三大基本定律
| 定律                 | 说明                                                                                         |
| -------------------- | -------------------------------------------------------------------------------------------- |
| **非凡特性不灭定律** | 非凡特性不会真正消失，只会从一处转移到另一处                                                 |
| **非凡特性守恒定律** | 每条途径的高序列特性总量固定。序列0与序列1无法共存——有序列0则无序列1；无序列0则最多三位序列1 |
| **非凡特性聚合定律** | 同途径的非凡特性会天然地相互吸引、聚合                                                       |

#### 3.3.2 扮演法（核心机制）
> *"魔药的名称就是掌握魔药力量的钥匙。"*

扮演法是消化魔药、防止失控的核心方法。人类服食魔药时会受到其中残留的精神烙印影响，累积疯狂乃至失控。**通过"扮演"魔药名称所代表的角色**，可以绕过阻碍、瓦解魔药内残余的精神影响，降低失控风险、加速消化魔药。

| 扮演法要点   | 说明                                                                                   |
| ------------ | -------------------------------------------------------------------------------------- |
| **核心原则** | 严格按照魔药名称的核心特质行事                                                         |
| **关键警示** | **"记住自己只是在扮演"**——不能迷失在魔药赋予的"角色"中，否则会弱化自我意识，被魔药同化 |
| **消化周期** | 低序列严格扮演下，少则一个月、多则半年即可彻底消化魔药                                 |
| **提前扮演** | 可根据不同魔药名称的扮演内涵，提前扮演以预先消化更高序列魔药                           |

#### 3.3.3 相邻途径与互换
- 22条途径分为**9组**，每组内的途径互为**相邻途径**
- 绝大多数途径在**序列5后可晋升到相邻途径的序列4**（占卜家/学徒/偷盗者从序列4开始）
- 转到不相邻途径：轻则半疯，重则失控，后续无法再晋升
- **特例**：不眠者/战士/收尸人组 ↔ 刺客/猎人组可互换

#### 3.3.4 晋升仪式与唯一性
- 序列5及以上晋升**必须辅以特定仪式**，仪式是稳定精神的锚点
- 晋升序列0（真神）需：本途径**全部三份序列1非凡特性** + **唯一性**
- 每途径唯一性**有且只有一份**，真神唯一
- 执掌唯一性的天使之王 ≈ 准神

#### 3.3.5 序列位格等级
| 等级   | 序列范围         | 说明                                             |
| ------ | ---------------- | ------------------------------------------------ |
| 低序列 | 序列9~8（古含7） | 序列9特性数量上万份                              |
| 中序列 | 序列7~5          | 不知扮演法则晋升极为危险                         |
| 圣者   | 序列4~3          | 获得神性，可展现神话生物形态；可设尊名、回应祈祷 |
| 天使   | 序列2~1          | 真正的神话生物，几乎无尽寿命；可回应全球祈祷     |
| 真神   | 序列0            | 需唯一性 + 三份序列1特性                         |
| 旧日   | 序列之上         | 需容纳本组源质 + 相邻途径序列1特性和唯一性       |

## 五、核心跑团规则提示
### 5.1 角色创建
- 推荐起始等级：序列9（新手）或序列8（有经验玩家）
- 每个角色只能选择一条途径，不能同时修炼多条途径
- 角色背景应与世界观相符，可选择普通人、教会成员、黑帮成员、冒险家等
- 每个角色应有自己的"锚"，这将影响角色的精神稳定度

### 5.2 核心属性
- **力量**：物理攻击力和负重能力
- **敏捷**：速度、反应和闪避能力
- **体质**：生命值和抵抗力
- **智力**：学习能力和逻辑思维
- **感知**：察觉危险和发现隐藏事物的能力
- **魅力**：社交能力和影响力
- **灵性**：非凡力量的基础，影响法术效果和精神抵抗力
- **疯狂值**：角色的精神稳定度，达到100将失控

### 5.3 魔药与扮演
- 获得魔药是提升序列的唯一途径
- 必须严格按照扮演法消化魔药，否则疯狂值会快速增加
- 扮演法的核心是"理解并践行对应序列的核心规则"
- 消化魔药需要时间，不能连续服用多瓶魔药

### 5.4 战斗规则
- 非凡战斗强调能力克制和战术运用
- 不同途径的非凡者有各自的优势和劣势
- 精神攻击和诅咒是常见的战斗方式
- 失控的非凡者比普通怪物更加危险

## 七、常见冒险钩子
1. **失踪案**：贝克兰德东区接连发生儿童失踪案，警方怀疑与某个邪教组织有关
2. **遗产继承**：一位远房亲戚去世，留给你一座古老的庄园，但庄园里似乎隐藏着可怕的秘密
3. **神秘信件**：你收到一封匿名信件，信中告诉你一个关于你家族的惊人真相
4. **考古发现**：一支考古队在南大陆发现了一座古老的神庙，但所有队员都神秘失踪了
5. **黑帮火并**：两个黑帮为了争夺地盘发生火并，背后似乎有非凡力量的介入
6. **魔药交易**：你偶然得知有一个地下魔药交易市场，那里可以买到各种稀有的魔药
7. **诅咒缠身**：你被一个古老的诅咒缠身，只有找到特定的物品才能解除诅咒
8. **教会任务**：你所在的教会交给你一个秘密任务，调查一个可疑的村庄

## 八、附录
### 8.1 常用术语表
- **非凡者**：服用魔药获得非凡力量的人
- **失控者**：未能正确消化魔药而变成怪物的非凡者
- **封印物**：拥有非凡力量的物品，通常带有负面效果
- **神秘学**：研究非凡力量的学问
- **灵界**：与现实世界平行的精神世界
- **星界**：更高维度的世界，真神居住的地方
- **神话生物形态**：非凡者达到序列4后可以变身的形态

### 8.2 常见封印物示例
- **封印物0-08"阿勒苏霍德之笔"**：可以书写未来，但会带来厄运
- **封印物1-29"特伦索斯特黄铜书"**：可以实现愿望，但会收取等价的代价
- **封印物2-01"审判之矛"**：可以审判任何罪恶，但使用者也会受到审判
- **封印物3-07"幸运石"**：可以带来好运，但会消耗使用者的生命力

### 8.3 跑团注意事项
- 强调探索和推理，而非单纯的战斗
- 注重氛围营造，让玩家感受到诡秘世界的黑暗与神秘
- 合理控制难度，避免玩家过早遇到无法战胜的敌人
- 鼓励玩家角色扮演，深入体验角色的内心世界
- 随时准备应对玩家的突发奇想，灵活调整剧情
